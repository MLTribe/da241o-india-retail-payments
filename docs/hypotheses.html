How to add or change one

  1. Open analysis/hypothesis_tests.py and copy an existing function such as s2. State the predicted direction ("<0" or ">0") before looking at the result.
  2. Build the tested series from the loaded data (12-month log changes remove seasonality) and return drift_hypothesis(...), or hypothesis(...) for a custom test.
  3. Add the function to REGISTER, then run python3 analysis/hypothesis_tests.py. It rewrites analysis/output/hypotheses.csv and docs/hypotheses-data.js, and this page updates.
  4. Hypotheses that need data we have not collected yet can be listed with pending(...) so they stay visible.

Method: drift tests use the mean 12-month log change with Newey-West (Bartlett, 12-lag) standard errors and report how many months fall on the same side of zero; regressions use the same estimator; the IMPS break uses a Quandt–Andrews sup-F search. Because monthly payment series are strongly persistent, p-values are indicative and effect sizes matter more. Data: NPCI UPI and IMPS product statistics, NPCI UPI P2P/P2M ecosystem statistics, RBI Payment System Indicators, MoSPI CPI Combined. Generated by analysis/hypothesis_tests.py. See the data sources.
